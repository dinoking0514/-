# 어설픈 용맹 기록실

이 폴더의 내용만 GitHub 저장소 최상위에 올리세요. 로그 분석 작업 폴더 전체를 올릴 필요가 없습니다.

- index.html: 세션·대화 목록, 검색 및 필터
- characters.html: 캐릭터 일람
- character.html: 캐릭터별 참가·등장 기록
- read.html: 대화 읽기, 인물 링크, 본문 검색, 회차·관련 이야기 이동
- data/: 게시에 필요한 검토된 대화와 목록

현재 2439개 이야기, 320개 인물 항목을 수록합니다. 원본 전체 처리율은 100.00%입니다. 원본 전체의 분류 검토를 마쳤습니다. 같은 이름을 구분할 근거가 부족한 표시는 개별 인물에 무리하게 합치지 않습니다.

## 게시

1. 공개 GitHub 저장소를 만듭니다.
2. 이 폴더의 내용(index.html, data 폴더, .nojekyll 등)을 저장소 최상위에 올립니다.
3. Settings → Pages → Deploy from a branch → main / (root) → Save.
4. 표시되는 사이트 주소에서 검색과 링크를 확인합니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 갱신

분석 작업 폴더에서 node 정리도구/build-site.mjs 를 실행한 뒤 이 폴더의 변경분을 다시 올립니다. 이 명령은 현재 정리 결과로 게시 파일만 생성하며, 원본 로그 분석을 재개하지 않습니다. 새 분석 내용을 반영하려면 먼저 기존 정리 빌드를 실행합니다.

게시-ID.json은 정리도구 폴더에 유지해야 이후에도 세션 주소를 보존할 수 있습니다. 원본 로그와 정리결과는 로컬에 그대로 남습니다.

파일이 많으므로 GitHub Desktop을 사용하는 게시 순서는 [게시안내.md](게시안내.md)를 참고하세요.

## 길드 이미지

[guild.html](guild.html)에 「(임시) 길드의 이미지」를 별도 수록합니다. 본관과 주변 시설, 길드원들의 생활화 30장을 모았으며 그림을 누르면 큰 이미지가 열립니다. 본관 스케치와 길드 배치도를 참고했고 실내는 생활 공간으로 해석한 장면입니다. 게시용 WebP와 미리보기는 이미지/길드/에 있으며 원본 PNG와 참고 자료는 Git에서 제외한 로컬 이미지/길드 이미지/ 및 자료/에 유지합니다. 유지 원고는 정리도구/site/guild.html, guild-gallery.mjs, guild-images.json과 guild-images/입니다.

## 캐릭터 시트

캐릭터 일람에서 인물을 선택하면 소개·평가·성향표와 참가 기록이 함께 열립니다. 현재 320개 인물·기록 항목의 시트를 수록합니다. 성향은 근거 대화를 바탕으로 한 편집 해석입니다. 자료가 부족한 축은 점수 없이 표시합니다. 모든 인물 시트에는 여섯 성향의 육각형과 해석 버튼이 표시됩니다. 추가된 서술 분석의 점수는 인용한 장면을 대조해 수동으로 작성하며 등장 횟수로 생성하지 않습니다. 근거가 부족한 축은 점수·점·면을 비워 두고, 여섯 축이 모두 평가된 경우에만 면으로 연결합니다. 단일·소수 장면은 장면 기반 소개·평가로 표시하고 장면 밖 논평에는 인물 성향표를 붙이지 않습니다. 기록이 부족한 인물도 여섯 축은 표시하되 확인되지 않은 성향에 점수를 부여하지 않습니다.

시트 원고는 분석 작업 폴더의 정리도구/site/character-sheets.mjs, character-sheets-requested.mjs, character-sheets-selected*.mjs, character-sheets-audrey.mjs, character-readings-completed.json, character-traits-completed.json, character-sheets-completed.json에서 관리하며, 사이트를 다시 생성해도 유지됩니다.

## 페이지 이동과 이어 읽기

세션 목록, 캐릭터 일람, 참가 기록, 로그 본문에서 페이지 번호를 입력하고 이동하거나 Enter를 누를 수 있습니다. 처음·끝과 가까운 페이지 번호 버튼도 제공합니다. 로그 위아래에 이동 도구가 있으며 검색과 인물 필터를 유지합니다.

로그의 ‘자동으로 다음 페이지 이어 읽기’를 켜면 읽는 구간 끝에 닿았을 때 다음 250개 대화를 아래에 추가합니다. 앞 대화와 읽던 위치를 유지하고, 검색 조건에 맞는 마지막 대화에서 멈춥니다. 켜기·끄기는 이 브라우저에 저장되며 처음 방문했을 때는 꺼져 있습니다. 페이지 번호로 직접 이동하거나 검색·필터를 바꾸면 해당 구간부터 다시 표시합니다.

정적 파일과 대화 데이터에는 내용에 따른 버전 주소를 붙여 이전 브라우저 캐시와 구분합니다. 이전 HTML 문서가 남아 있는 첫 갱신은 페이지 주소에 새 v 값을 붙여 열거나 새로고침할 수 있습니다.

## 일러스트 화풍

일러스트집에서 기본 화풍을 고르면 해당 버전이 있는 그림을 보여주고, 없는 그림은 기존 현대 판타지풍으로 표시합니다. 선택은 이 브라우저에 저장되며 세션 본문과 캐릭터의 이야기 미리보기에도 적용됩니다. URL의 style 값으로 특정 화풍을 공유할 수 있습니다. 다른 화풍 버전이 있는 그림만 보기 필터는 선택한 화풍의 종류와 관계없이 다른 버전이 하나라도 있는 장면을 모읍니다. 각 그림의 화풍 메뉴에서는 해당 그림에 있는 버전만 선택할 수 있습니다.

기존 장면·인물·대화 앵커와 현대 판타지풍 이미지는 정리도구/site/illustrations.json 및 illustration-images/에 유지합니다. 추가 버전은 illustration-variants.json과 illustration-variant-images/에서 관리합니다. 화풍 이름과 번호는 정리도구/작풍-목록.json을 사용합니다. 버전을 추가할 때는 기존 장면 ID와 화풍 ID, 원본 크기, 미리보기 너비를 기록하고 node 정리도구/build-site.mjs를 실행합니다. 게시용 추가 이미지는 이미지/일러스트/화풍/에 생성됩니다. 원본 참고 자료와 제작 기록은 공개 데이터에 포함하지 않습니다.

## 오너 묶음

캐릭터 묶음.txt와 검토된 닉네임을 바탕으로 현재 오너의 캐릭터들을 연결합니다. 캐릭터 일람에서 오너 묶음을 선택하거나 닉네임으로 검색할 수 있습니다. 캐릭터 시트에는 같은 오너의 인물과 확인된 양도 이력을 표시합니다. 프로필명은 장면별 표시이며 모든 발언의 작성자나 캐릭터 소유를 뜻하지 않습니다. GM·대리 연기만으로 오너 묶음을 합치지 않습니다.
